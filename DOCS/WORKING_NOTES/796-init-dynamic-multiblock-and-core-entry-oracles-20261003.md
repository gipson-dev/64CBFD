# Init Dynamic, Multiblock, And Core Entry Oracles

Date: 2026-10-03.

## Result

Eleven new tests connect the dynamic parser, table builder, decoder, stored
leaf, block loop, and outer entrypoints in the bounded instruction-word
fixture. Complete dynamic streams agree with zlib, including a mixed four-
block stream and the final input-cursor rewind. Production Init remains
assembly; this is oracle/interface recovery, not a C conversion or guest
hardware qualification. It follows
[Note 795](795-init-compressed-decoder-fixed-stream-and-error-oracles-20261003.md).

## Connected Fixture

`tools/tests/test_init_decompressor_streams.py` extends the existing fixed
table fixture with the retained words for `func_10006240`, `func_1000625C`,
`func_1000632C`, `func_10006380`, `func_10006424`, `func_10006828`, and
`func_1000696C`. No instruction is replaced to force a result. Literal masks,
base/extra arrays, and code-length permutation are supplied at their retained
addresses. The fixed wrapper still consumes its absolute table pointers.

The shared runner additionally models the used NOR, BLTZ, BGTZL, and
big-endian LWL/LWR pair, and records entered instruction addresses to verify
the intended branches/helpers actually execute. It remains a low-word,
bounded model, not a general MIPS emulator. Input lookahead padding and
explicit fixture memory remain acceptance limits.

## Dynamic Parser Evidence

A separately encoded dynamic fixture declares 257 literal/length symbols and
one distance symbol. Its code-length alphabet is complete and uses symbols
0, 1, 16, 17, and 18. Direct entered-address assertions establish that all
three repeat paths execute, along with three table-builder calls and the
compressed decoder. Literal A and end marker have one-bit codes; the single
one-bit distance code is accepted by the retained builder contract.

The fixture covers six-value previous-length repetition, ten-value zero
repetition, and long zero runs of 48/138/52. It produces one literal A, and
zlib independently accepts the same stream/output. Two additional complete
dynamic streams are generated by zlib from repeated text and a repeated
128-byte alphabet; both match through the connected model.

Two malformed conditions are distinguished:

- Repeating beyond the declared combined alphabet rejects before output.
- Repeat symbol 16 before any prior length is accepted by this model using
  the parser's initialized previous-length value zero; the synthetic stream
  produces A, while zlib rejects it. This is pinned as model-observed behavior,
  not a proven retail gameplay defect, and is not silently repaired.

Header fields yielding 287/288 literal symbols or 31/32 distance symbols
reject with status one before any builder call. This documents the retained
parser bounds, not a general standards-compliance claim.

The complete dynamic parser body, 1,028 bytes, is compared with retail ROM
when available. SHA-256:

## Whole-Stream And Entry Contract

The mixed fixture contains stored XY, fixed BC, an empty stored block that
realigns the boundary, then final dynamic A. Zlib and the model both produce
`XYBCA`. Entry counters prove four dispatcher calls, two stored calls, one
fixed wrapper call, and one dynamic call. The returned input cursor equals
the first byte after the encoded stream, and the remaining buffered bit count
is below eight. Reserved block type three returns status two from the loop.

Outer core tests cover both the direct `func_1000625C` entry and its
`func_10006240` wrapper:

- Header 0x1172 skips two bytes; another header skips four.
- All four starting input alignments succeed through the retained unaligned
  header load pair.
- s0..s7, gp, fp, sp, and RA are restored on the covered successful paths.
- Core output-base/count/limit setup executes, and success returns one for
  the one-byte dynamic output.
- A positive smaller workspace displacement selects limit 8,192; ordinary
  fixture workspace below output is excluded from that minimum.
- Reserved-block failure returns zero without output.
- A valid stored XY block followed by a failing dynamic repeat returns zero
  while retaining both already written bytes and published count two.

These tests establish selected connected entry behavior, not the exception
caller's CP0/FPR save/restore execution, every malformed stream, allocation
capacity, or physical bounds enforcement.

## Next C Work

The valid stored/fixed/dynamic paths now have connected behavioral oracles.
Begin an isolated semantic C implementation with explicit input cursor,
reservoir/bit count, output base/count/limit, workspace, allocation index,
table outputs, and scratch arrays. Preserve publication timing and the pinned
exceptional behavior rather than substituting zlib wholesale or inventing a
defensive error policy.

Compare that C implementation with these instruction-word oracles before
extracting any production assembly owner. Invalid lengths/oversubscription,
workspace exhaustion, untouched/aliased scratch, and exception/FPR context
still need stronger qualification. A complete matching Init image remains
the production acceptance gate; an isolated semantic candidate does not
raise conversion totals.
