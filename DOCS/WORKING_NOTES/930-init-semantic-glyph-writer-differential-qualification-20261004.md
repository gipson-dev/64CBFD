# Init Semantic Glyph Writer Differential Qualification

Date: 2026-10-04. Production baseline: `ec2bf64f`.

## Semantic C Trial

`tools/experiments/init_glyph_writer_semantic.c` implements the recovered
glyph writer using an ordinary four-argument ABI: cursor address, destination
displacement, glyph index and font address. Its return value is cursor + 16.
Unsigned 32-bit address calculations model the retail low-word arithmetic;
volatile byte reads and halfword stores preserve each external memory access.
Each row captures its font byte once, then writes eight pixels to both
destinations in first/second order. Later font bytes remain late reads, so
earlier pixel stores can affect them when the font overlaps output.

This is an isolated semantic replacement trial, not production C ownership.
It does not preserve the retail leaf's nonstandard live-register interface
without a connected adapter. Notes 928/929 describe that interface.

All three IDO builds are warning-clean. O2 unrolls the inner loop in groups
of four pixels. Disabling unrolling gives the smallest candidate, but it is
still one instruction larger than the retail leaf, before any adapter cost.
The conditional pixel selection introduces a branch/jump shape different
from retail; fitting and byte-exact matching are not achieved here.

Compiled images are independently linked at experimental address
`0x10007D20`; this does not occupy or replace the production slot. Body counts
exclude trailing linker padding. Measurements and disassembly are retained
under ignored `conker/build/init-glyph-semantic/` and regenerated by the test.

## Differential Qualification

`tools/tests/test_init_glyph_semantic.py` runs the original retail leaf and
each compiled candidate in the existing guest instruction fixture. It checks:

- The complete interleaved external read/write trace: address, width, value
  and ordering, including the eight font-byte reads.
- Complete non-stack memory equality and matching cursor results.
- Ordinary ABI callee-register, SP and return-link preservation.
- Write fences for destination rows and a separate bounded trial stack range.

Each profile runs 256 varied byte-pattern/glyph-offset fixtures, four
overlapping-destination fixtures and six font/output alias fixtures: **266
paired fixtures per profile / 798 paired fixtures total**. Font aliases cover
pixels in the first output row and the following output row, testing that
later reads observe earlier stores. Destination cases include exact alias
and offsets two, eight and fourteen bytes.

O1 uses an ordinary 32-byte frame. Its private stack operations are excluded
from the external trace/memory equality comparison, explicitly not hidden as
a retail match; the fixtures bound those writes and verify SP restoration.
The two O2 candidates are frameless. A real adapter's stack reservation and
caller-state preservation have not been established by these tests.

```sh
python3 -m unittest tools.tests.test_init_glyph_semantic tools.tests.test_init_glyph_formatters tools.tests.test_init_glyph_register_contract tools.tests.test_init_diagnostic_cleanup -q -f
```

All sixteen combined tests pass in 21.237 seconds, no skips. Earlier
separate semantic checks passed before interleaved trace assertions were
added; the combined receipt above includes those stronger assertions.

These are bounded low-word MIPS instruction fixtures, not physical hardware
or framebuffer-allocation evidence. Arbitrary invalid addresses, every
possible alias geometry and connected production adapter execution remain
unqualified. No production rebuild or new whole-section match is claimed.
